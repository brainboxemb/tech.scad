# User projects

This index contains concrete CAD projects in the wider SCAD landscape.

Inclusion here means that a repository is relevant to the SCAD/CAD catalog. It
does **not** imply that the project has already been migrated to the newest
`template.scad-project` structure or currently uses every shared tool.

| Repository | Purpose |
| --- | --- |
| [`2026-003-01.cad.garden-tool-cart`](https://github.com/brainboxemb/2026-003-01.cad.garden-tool-cart) | Modular storage solutions for a mobile garden tool rack. |
| [`2026-004-01.cad.metabo-tsu-slot-insert`](https://github.com/brainboxemb/2026-004-01.cad.metabo-tsu-slot-insert) | Insert that locates mounting bolts in a Metabo TSU table-saw stand. |
| [`2026-005-01.cad.aluminium-profile-mft`](https://github.com/brainboxemb/2026-005-01.cad.aluminium-profile-mft) | Aluminium-extrusion MFT-style multifunction workbench. |
| [`2026-006-01.cad.HUB75-display-frame`](https://github.com/brainboxemb/2026-006-01.cad.HUB75-display-frame) | Mechanical frame for HUB75 LED matrix panels. |
| [`2026-006-02.cad.HUB75-display-case`](https://github.com/brainboxemb/2026-006-02.cad.HUB75-display-case) | Wooden enclosure and carry structure for a HUB75 LED display. |
